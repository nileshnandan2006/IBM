Pest & Disease Detection Agent — Multimodal

Farmer reported: yellowing leaves, white powdery spots, stunted growth. Image upload supported (base64 encoded).
Primary DiagnosisPowdery Mildew (Erysiphe spp.)
ConfidenceHigh
SeverityMEDIUM
Affected CropsWheat, grape, cucurbits, mango

Treatment Plan

  • Spray Sulphur 80 WP @ 3 g/L or Hexaconazole 5 EC @ 1 mL/L water
  • Apply potassium bicarbonate solution (5 g/L) for organic alternative
  • Remove and destroy heavily infected plant parts before spraying
  • Repeat application after 10–14 days if symptoms persist
  • Spray during early morning or late evening — avoid midday heat

Prevention Measures

  • Ensure good air circulation by maintaining recommended plant spacing (18–20 cm rows)
  • Avoid high nitrogen application that promotes lush, susceptible growth
  • Select resistant varieties for next season (HD 2967 has moderate resistance)
  • Maintain field humidity below 85% — avoid over-irrigation

Q: Best practices for wheat cultivation in loam soil?
Wheat grows well in loam soils with good drainage and pH 6.5–7.5. Seed rate should be 100–125 kg/ha with a well-prepared seed bed. Apply 150:60:40 kg/ha NPK with split nitrogen applications at CRI, tillering, and jointing stages. Irrigate at five critical stages. Harvest when grain moisture reaches 14% and husks are golden-dry. For loam soils, ensure organic matter >2.5% by incorporating crop residue or compost.
Wheat cultivation guidelines Soil health management Climate-smart agriculture
Q: Government schemes for farmer income support?
PM-KISAN (Pradhan Mantri Kisan Samman Nidhi) provides ₹6,000/year to eligible farmer families in three equal instalments. PMFBY (Pradhan Mantri Fasal Bima Yojana) offers crop insurance at 2% premium for Kharif and 1.5% for Rabi crops. Kisan Credit Card (KCC) provides short-term credit at 4% interest for crop production. PM-KUSUM supports installation of solar pumps. Farmers can access these via the e-Nam portal, nearest CSC, or cooperative bank.

CLI Quick Start

# 1. Install dependencies
pip install ibm-watsonx-ai python-dotenv requests

# 2. Configure WatsonX credentials
cp .env.example .env   # Fill in API key + project ID

# 3. Run full demo advisory
python -m smart_farming.main demo --farmer raj

# 4. Single knowledge query
python -m smart_farming.main query --question "How to manage wheat rust?" --crop wheat

# 5. Pest detection
python -m smart_farming.main pest --crop rice --symptoms "diamond lesions" "gray center"

# 6. Weather + irrigation
python -m smart_farming.main weather --lat 30.9 --lon 75.8 --crop wheat --area 2.5

# 7. Market analysis
python -m smart_farming.main market --crop cotton --area 4.0
